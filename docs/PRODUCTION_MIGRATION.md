## Проверка качества накопленных данных

В `ml_ads` 2117 записей; модель распознана у 1271. У 38 распознанных записей память предположена. У 11 записей отсутствует описание; у 651 записи iPhone отсутствует распознанная ёмкость АКБ. Нераспознанная модель может относиться к моделям вне установленного белого списка; это не автоматическое доказательство ошибки парсера.

225 старых эвристических цен в ML-таблице сохранены отдельно. Подтверждённых цен сделок в этой схеме нет. Накопление полезно для анализа цен объявлений; точность прогноза сделки по этим числам ещё не измерена.

## Текущий этап и переключение

Несколько недель собираем данные и контролируем полноту, свежесть и качество. Возвращение к выкупам отложено.

Текущая рабочая смена на GitHub продолжает работу. Новая версия туда не отправлялась, релиз не изменялся, смена не останавливалась. Перед переключением нужно дождаться последнего сохранения старой смены, остановить дальнейшую старую цепочку и перенести **именно самое свежее** состояние. Эту проверенную копию более раннего сохранения нельзя молча выдавать за актуальную БД на момент будущего переключения.

Версия `v4.0.1` поддерживает существующий публичный `debon25/snipser` и `db-state`. Прежнее избыточное требование отдельного приватного хранилища снято. База по-прежнему исключена из Git; доступность файлов Release определяется видимостью выбранного репозитория. Работа с отдельным приватным хранилищем остаётся возможной, его БД не должна попадать в публичный аварийный artifact.

Исходная копия БД и настроек дополнительно упакована в `outputs/snipser-db-state-original-20261126.zip` вне Git проекта. Это резервная копия сохранения с указанным выше временем, а не файл для автоматической замены будущей актуальной БД.
